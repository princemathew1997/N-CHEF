# N-CHEF | Cuisine Head guide

Revision: 22 October 2026 | N-CHEF 2.3.0

Your role covers ingredient requests and receiving deliveries for your assigned outlet and cuisine. Existing Chef credentials and assignments remain valid.

## Start your day

Sign-in opens My Requests. Select the N-CHEF logo to return there. Use Receive Order directly in the sidebar; there is no Stock menu to expand. On mobile, open the menu button to choose a page. Notifications and menu badges highlight work requiring attention.

## Request ingredients and edit an initial order

1. Open My Requests and select Raise Request. Your request date is today's IST date; Cuisine Heads cannot backdate requests.
2. If requests already exist for this date and outlet, review the existing item names and quantities first. The window uses the available screen space and scrolls when necessary.
3. Use Edit quantity for an initial request while editing is permitted. After Executive Chef acceptance, the request is locked for Cuisine Head editing.
4. Choose Place new order only for additional items. An item already present in the initial order cannot be selected again; use the initial order's edit option when available.
5. For new items, select ingredients, open Review & Submit, enter quantities and submit. Check the saved status in My Requests.

Executive Chef reviews and consolidates requests. Purchaser or Admin approves the consolidated order and arranges procurement or distribution. An approval is not a delivery confirmation. Rejected requests retain their reason; coordinate with Executive Chef for review and resubmission.

## Receive a delivery

Open Receive Order. Deliveries are grouped into cards by dispatch to a cuisine. Two dispatches from the same order remain separate cards. Check the cuisine, order reference, time and item counts, then expand the relevant card to review its items. Counts refer to items, not a combined quantity across different units.

1. For a shortage, rejected goods or other discrepancy, use the item's Confirm / report issue button first.
2. Enter the actual received quantity. Choose Less quantity, Not available, Quality issues or Other as appropriate, and enter the affected quantity. Other requires a message. For Less quantity, the affected quantity must equal issued minus received.
3. Save each problem before accepting the remainder.
4. When the other items in this delivery are correct, select Accept all remaining and confirm. This accepts only the still-awaiting items in that one card. Previously reported issues and handled items retain their outcomes.

Stock was deducted when the store issued it. Confirming receipt does not deduct it again. A replacement is a separate delivery and needs its own confirmation. You see deliveries permitted by your outlet/cuisine assignments and personal request links.

## Find pending and older deliveries

Needs attention includes unfinished deliveries from earlier days, so yesterday's unconfirmed items are not hidden. Today shows deliveries dispatched today, including handled ones. History shows fully handled deliveries. A card with an unresolved issue remains unfinished.

Open Filters to narrow by the available outlet/cuisine, status, item, order reference or IST date range, then Apply filters. Use the page controls for older results and expand a card to load its item lines. View request shows the originating request information where linked.

## Notifications and follow-up

A delivery issue notifies the responsible Executive Chef, Purchaser and Admin. Purchaser or Admin handles the resolution. Check Notifications for reasons and updates; mark items read after reviewing them. Existing unread alerts remain listed after sign-in without being announced as new alerts again.

Visible sessions refresh shared changes about every three seconds and when brought into focus. If a save reports that data changed, refresh and review the latest record before retrying. Do not assume a failed save was accepted; check the saved status.
